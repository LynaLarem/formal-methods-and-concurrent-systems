# Formal Methods and Concurrent Systems

This repository brings together selected academic projects, practical assignments, and implementations developed during my studies in **Software Engineering and Intelligent Systems**.

It focuses on formal methods, system modeling and verification, concurrent programming, and distributed systems.

## Topics Covered

- **Formal Methods & Model Checking:** Finite-state automata, formal specification, temporal logic (LTL and CTL), and model checking.
- **Petri Nets:** Modeling and analysis of discrete-event systems, reachability, boundedness, and liveness.
- **Algorithms & Graph Theory:** Graph-based models, algorithm design, and state-space analysis.
- **Concurrent Programming:** Processes, threads, synchronization, mutual exclusion, critical sections, and deadlock handling.
- **Distributed Systems:** Message passing, MPI, distributed synchronization, and mutual exclusion algorithms.

## Repository Structure

- `model-checking/` — System modeling and verification exercises using NuSMV.
- `petri-nets/` — Petri net modeling, analysis, and the Karp–Miller algorithm implementation.
- `concurrent-programming/` — Concurrent applications and practical assignments.
- `distributed-systems/` — MPI exercises and distributed algorithms.

## Tools & Technologies

Python · NuSMV · TINA · MPI
